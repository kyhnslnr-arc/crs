Amended Common Reporting Standard (CRS)

XML Schema v3.0 Diagrams

User Guide for Tax Administrations

Schema Version: 3.0

Source: OECD Common Reporting Standard documentation

Overall CRS_OECD Structure

Root element: CRS_OECD with version attribute
Contains: MessageSpec and CrsBody elements
Description: The top-level element that wraps the entire CRS message structure
CRS_OECD
xsd:element
Attribute: version (optional, string, 1-10 chars)

MessageSpec Element

Location: First child of CRS_OECD
Purpose: Identifies the Tax Administration sending the message
Contains: SendingCompanyIN, TransmittingCountry, ReceivingCountry, MessageType, Warning, Contact, MessageRefId, MessageTypeIndic, CorrMessageRefId, ReportingPeriod, Timestamp
MessageSpec
MessageSpec_Type
Mandatory elements: MessageType, MessageRefId, MessageTypeIndic, ReportingPeriod, Timestamp
Optional elements: SendingCompanyIN, Warning, Contact, CorrMessageRefId

CrsBody Element

Location: Second child of CRS_OECD (0..unbounded)
Purpose: Contains reporting financial institution and account reports
Contains: ReportingFI, ReportingGroup (0..unbounded)
CrsBody
CrsBody_Type
ReportingFI: CorrectableOrganisationParty_Type (1..1)
ReportingGroup: xsd:complexType (inline), 0..unbounded

Reporting Financial Institution (ReportingFI)

Location: First element of CrsBody
Purpose: Identifies the reporting financial institution
Contains: DocSpec, ResCountryCode (0..unbounded), IN (0..unbounded), Name (1..unbounded), Address (0..unbounded)
ReportingFI
CorrectableOrganisationParty_Type
Mandatory: DocSpec, Name
Optional: ResCountryCode, IN, Address

ReportingGroup Element

Location: Child of CrsBody (0..unbounded)
Purpose: Groups account reports by sponsor, intermediary, or pool
Contains: Sponsor, Intermediary (0..1 each), AccountReport (0..unbounded), PoolReport (0..unbounded)
ReportingGroup
xsd:complexType (inline)
AccountReport: CorrectableAccountReport_Type (0..unbounded)
PoolReport: ftc:CorrectablePoolReport_Type (0..unbounded)

CorrectableAccountReport

Location: Child of ReportingGroup/AccountReport
Purpose: Contains individual account reporting data
Contains: DocSpec, AccountNumber, AccountHolder, ControllingPerson (0..unbounded), AccountBalance, Payment (0..unbounded), DDProcedure, AccountType, JointAccount (0..1)
CorrectableAccountReport
xsd:complexType
Mandatory: DocSpec, AccountNumber, AccountHolder, AccountBalance, DDProcedure, AccountType
Optional: ControllingPerson, Payment, JointAccount

AccountHolder Element

Location: Child of CorrectableAccountReport
Purpose: Identifies the account holder
Contains: EquityInterestType (0..unbounded), SelfCert, Individual/Organisation (choice), AcctHolderType
AccountHolder
AccountHolder_Type
Choice: Individual (PersonParty_Type) or Organisation (OrganisationParty_Type)
Mandatory: SelfCert, AcctHolderType
Individual contains: ResCountryCode (1..unbounded), TIN (0..unbounded), Name (1..unbounded), Address (0..unbounded), Nationality (0..unbounded), BirthInfo (0..1)
Organisation contains: ResCountryCode (0..unbounded), IN (0..unbounded), Name (1..unbounded), Address (0..unbounded)

ControllingPerson Element

Location: Child of CorrectableAccountReport (0..unbounded)
Purpose: Identifies controlling persons for the account
Contains: Individual, CtrlgPersonType (1..unbounded), SelfCert
ControllingPerson
xsd:complexType
Individual: PersonParty_Type
CtrlgPersonType: CRS801-CRS813, CRS800 (0..unbounded)
Mandatory: SelfCert (1..1)

AccountNumber Element

Location: Child of CorrectableAccountReport (1..1)
Purpose: Identifies the account number
Contains: AcctNumberType (required attribute), UndocumentedAccount, ClosedAccount, DormantAccount (optional attributes)
AccountNumber
FIAccountNumber_Type
Attributes: AcctNumberType (required, enumeration), UndocumentedAccount, ClosedAccount, DormantAccount (all optional boolean)

DocSpec Element

Location: Child of ReportingFI and AccountReport (1..1)
Purpose: Document specification identifying the report type
Contains: DocTypeIndic (required), DocRefId (required)
DocSpec
stf:DocSpec_Type
Mandatory: DocTypeIndic, DocRefId
DocTypeIndic: OECD1 (initial), OECD2 (correction), OECD0 (resend)
DocRefId: Format: country code + unique identifier

Individual Account Holder

Location: Choice element within AccountHolder (1..1)
Purpose: Identifies a natural person as account holder
Contains: ResCountryCode (1..unbounded), TIN (0..unbounded), Name (1..unbounded), Address (0..unbounded), Nationality (0..unbounded), BirthInfo (0..1)
Individual
PersonParty_Type
BirthInfo: BirthDate (0..1), City (0..1), CountryInfo (0..1)
CountryInfo: CountryCode or FormerCountryName

Organisation Account Holder

Location: Choice element within AccountHolder (1..1)
Purpose: Identifies an organisation as account holder
Contains: ResCountryCode (0..unbounded), IN (0..unbounded), Name (1..unbounded), Address (0..unbounded)
Organisation
OrganisationParty_Type
Mandatory: Name
Optional: ResCountryCode, IN, Address

EquityInterestType

Location: Child of AccountHolder (0..unbounded)
Purpose: Identifies the type of equity interest
Contains: CRS401-CRS410 enumeration values
EquityInterestType
CRS401-CRS410 enumeration
Values: CRS401 (settlor), CRS402 (trustee), CRS403 (protector), CRS404 (beneficiary), CRS405 (other), CRS406 (settlor-equivalent), CRS407 (trustee-equivalent), CRS408 (protector-equivalent), CRS409 (beneficiary-equivalent), CRS410 (other-equivalent)

SelfCertification Element

Location: Child of AccountHolder (1..1) and ControllingPerson (1..1)
Purpose: Identifies whether valid self-certification was provided
Values: CRS901 (True), CRS902 (False), CRS900 (not reported)
For ControllingPerson: CRS1001 (True), CRS1002 (False), CRS1000 (not reported)
SelfCert
CRS901/902/900 or CRS1001/1002/1000 enumeration

AccountType Element

Location: Child of CorrectableAccountReport (1..1)
Purpose: Identifies the type of financial account
Values: CRS1101 (Depository), CRS1102 (Custodial), CRS1103 (Insurance/Annuity), CRS1104 (Investment Entity interest)
AccountType
CRS1101-CRS1104 enumeration

Due Diligence Procedure

Location: Child of CorrectableAccountReport (1..1)
Purpose: Identifies the due diligence procedure applied
Values: CRS1201 (New account), CRS1202 (Pre-existing account)
DDProcedure
CRS1201/CRS1202 enumeration

JointAccount Element

Location: Child of CorrectableAccountReport (0..1)
Purpose: Indicates whether account has joint holders
Contains: Number (1..200, integer)
JointAccount
xsd:complexType
Number: 1..200 (integer, how many joint holders)

NamePerson Element

Location: Child of Individual or Organisation (1..unbounded)
Purpose: Contains person/organisation name components
Contains: PrecedingTitle, Title (0..unbounded), FirstName, MiddleName (0..unbounded), NamePrefix, LastName, GenerationIdentifier (0..unbounded), Suffix (0..unbounded), GeneralSuffix (0..1)
NamePerson
xsd:complexType
Attributes: nameType (optional, OECDNameType enumeration)
Title: 0..unbounded (e.g., Mr, Dr, Ms)
FirstName: Given name
LastName: Family name or company name

BirthInfo Element

Location: Child of Individual (0..1) within AccountHolder
Purpose: Identifies birth information of the person
Contains: BirthDate (0..1), City (0..1), CitySubentity (0..1), CountryInfo (0..1)
BirthInfo
xsd:complexType
CountryInfo: Choice between CountryCode or FormerCountryName

ControllingPersonType Element

Location: Child of ControllingPerson (1..unbounded)
Purpose: Identifies the type of controlling person
Values: CRS801-CRS813 plus CRS800 (not reported)
ControllingPersonType
CRS801-CRS813/CRS800 enumeration
CRS801: CP of legal person - ownership
CRS802: CP of legal person - other means
CRS803: CP of legal person - senior managing official
CRS804-CRS807: CP of legal arrangement - trust (settlor/trustee/protector/beneficiary)
CRS808: CP of legal arrangement - trust - other
CRS809-CRS813: CP of legal arrangement - other (settlor-equivalent, trustee-equivalent, protector-equivalent, beneficiary-equivalent, other-equivalent)
CRS800: Not reported (transitional measure)

Tax Identification Number (TIN)

Location: Child of Individual (0..unbounded) or Organisation (0..unbounded) within AccountHolder
Purpose: Identifies the tax identification number
Attributes: issuedBy (optional, country code), INType (optional, string)
TIN
cfc:TIN_Type
issuedBy: Optional country code of issuing country
INType: Optional identification number type description

NameOrganisation Element

Location: Child of Organisation (1..unbounded) within AccountHolder
Purpose: Identifies the organisation name
Contains: Value as string (no structured components like Individual Name)
NameOrganisation
cfc:NameOrganisation_Type

Address Element

Location: Child of Individual, Organisation, ReportingFI within AccountHolder/ReportingFI (0..unbounded)
Purpose: Identifies the address
Contains: Street, BuildingIdentifier, DistrictName, PostCode, City, CountryCode
Address
cfc:Address_Type
CountryCode: Optional, identifies country
Street: Optional
BuildingIdentifier: Optional (e.g., "No: 100")
DistrictName: Optional (e.g., "Levent")
PostCode: Optional
City: Optional

Sponsor/Intermediary Elements

Location: Child of ReportingGroup (0..1 each)
Purpose: Identify sponsor and intermediary financial institutions
Contains: Same structure as CorrectableOrganisationParty_Type
Sponsor / Intermediary
CorrectableOrganisationParty_Type
Optional elements: DocSpec, ResCountryCode, IN, Name, Address

PoolReport Element

Location: Child of ReportingGroup (0..unbounded)
Purpose: Identifies pooled account reports
Type: ftc:CorrectablePoolReport_Type
PoolReport
ftc:CorrectablePoolReport_Type
